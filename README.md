# game

🦠 Вирус-Паника
Мини-игра на реакцию и меткость — прямо в браузере, без установки и регистрации.

Открой по QR-коду на телефоне или заходи с компьютера — и играй. Один HTML-файл, ноль зависимостей, работает офлайн.

🎮 О чём игра
На игровом поле расползлись вирусы 🦠👾🧫 — они хаотично летают, отскакивают от стенок и портят всё вокруг. Вместе с ними на поле рассыпаны полезные фрукты и овощи 🍎🥕🍇 — их трогать нельзя.

Твоя задача — перетаскивать вирусы в био-утилизатор ☣️ внизу экрана и очистить поле до того, как истечёт время.

✨ Как играть
Действие	Результат
🦠 Тащишь вирус в утилизатор	+10 очков и частицы
⚡ Убираешь вирусы подряд быстро	Комбо-бонус (до +20 за штуку)
🍎 Тащишь фрукт в утилизатор	−5 очков, комбо сгорает
⏱️ Успел за отведённое время	Бонус за скорость ×3 и новый уровень
💀 Время кончилось	Конец игры, рекорд сохраняется
🔥 Особенности
Drag & Drop — управление мышью на ПК и пальцем на телефоне.

Динамические уровни — с каждым уровнем вирусов больше, они быстрее, а времени меньше.

Комбо-система — за быстрые ходы получаешь увеличивающийся бонус.

Частицы и анимации — взрывы, всплывающие очки, свечение утилизатора.

Процедурный звук — все звуки генерируются через Web Audio API, никаких mp3.

Сохранение рекорда — через localStorage, показывается на стартовом экране.

Полностью адаптивно — от маленьких смартфонов до больших мониторов, с учётом safe-area (вырезы iPhone).

Один файл — весь код (HTML + CSS + JS) внутри index.html. Просто залей на GitHub Pages и всё.
